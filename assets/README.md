# Logo

- `logo-lfi-2026.png` : logo de La France insoumise (version 2026), copie du fichier
  [LOGO-LFI-2026.png](https://commons.wikimedia.org/wiki/File:LOGO-LFI-2026.png) de
  Wikimedia Commons (source indiquée : https://lafranceinsoumise.fr/).
- `../.claude-plugin/icon.png` : le symbole φ découpé dans ce même fichier, centré sur un
  carré transparent de 512 px, sans redimensionnement, comme icône du plugin.

Wikimedia Commons classe ce logo dans le **domaine public** : trop simple pour être protégé
par le droit d’auteur. C’est néanmoins une **marque déposée** de La France insoumise, et ce
statut est indépendant du droit d’auteur. Il n’est donc couvert ni par la licence
CC BY-NC-SA du dossier `doc/`, ni par l’AGPL du code.

Ce dépôt est un projet indépendant, sans lien avec La France insoumise et non validé par
elle. Le logo sert uniquement à identifier le programme dont il est question.
